## 为什么要做

唯一目标是提高正式综合分，不要求某个训练算法必须成功。

1. 综合分80%来自抽取，因此先优化议题、证据与立场。历史诊断显示证据多已逐字引用，问题更可能在选择和概括口径，而不是不会抄原文。
2. 将联合任务拆为“证据先行抽取”和“逐卡未来生成”，检验两任务是否互相干扰；仅字段重排不等于已证明证据推理改善，必须正式评分验收。
3. B1和S1都只使用同一2000条fit，控制训练量变化。现有全量2400条基线只作整体参照，不能用它直接归因任务结构收益。
4. 初始生成器不训练于400条holdout，随后用真实生成候选构造质量有明确差距的偏好对；不能拿全量训练适配器冒充未见过样本。
5. 偏好优化比较DPO与可靠正例再SFT（RFT）。候选竞争方案是抽取RFT+未来DPO，但只保留实测有效模块，训练loss下降不等于涨分。

## 接续决策

完成SFT后实现完整预测与验收，再决定是否推进预测卡增强、候选生成和偏好训练。当前队列不会自动跳进尚未实现的DPO。重复val比较仅作探索，100条偏好确认集不参与梯度训练。未知失败停止告警，不自动改变训练配置。

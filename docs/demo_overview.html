1赛题任务：输入一篇文档，输出结构化情报

给定外交 / 时政长文（约 1500 字），抽取「议题观点」并预测「未来表态」。

输入

文档类型（记者会 / 联合声明 / 评论文章…）、发布日期、正文全文。

文档类型：国际新闻报道
发布日期：2025-07-26

【文档正文】
2025年7月26日，全国党史学习教育经验交流会在北京隆重召开……
（约 1500 字）
输出（一个 JSON） 
{
  "issue_list": [
    { "issue_name": "反对脱钩断链",
      "stance": "support",
      "argument_chain": ["原文原句1", "原文原句2"] },
    { "issue_name": "…", "stance": "…", "argument_chain": ["…"] }
  ],
  "future_argument": ["与第1张卡对应的未来表态预测，80~120字", "…"]
}

• 证据链必须逐字来自原文　• future_argument 与卡片一一对应

数据

train 2400 篇（有答案）
val 300 篇（有答案，自查用）
test 300 篇（无答案，交卷）

基座

官方指定 Qwen3-32B；本机先用 Qwen3-14B 验证与优化流程，正式提交再上 32B。

合规

训练 / 推理统一关闭思考模式（enable_thinking=False），复刻官方空 think 块忽略策略。

2评分规则：80% 抽取 + 20% 预测

理解评分是理解所有实验的前提——很多"看起来该涨"的操作，都是被规则本身否掉的。

观点抽取（占 80%）
①
立场必须完全一致才能配对 —— 硬门槛
②
语义等价分 = 0.4×议题名相似度 + 0.6×证据链相似度，>0.7 才算答对
③
一对一匹配（每张预测卡最多配一张标准卡）
④
乘质量系数 α（证据越像原文越高）

P = NC / Np　R = NC / Ng　F1 = 2PR/(P+R)
抽取得分 = F1 × α

未来观点预测（占 20%）

把预测的「未来表态」与标准答案比对：

ROUGE-L
字面重合度
BERTScore
语义相似度

预测得分 = (ROUGE-L + BERTScore) / 2

综合分 = 0.8 × (F1 × α) + 0.2 × 预测得分

术语：NC 配对成功数 ｜ Np 预测卡数 ｜ Ng 金标卡数 ｜ α 证据像原文的系数

4实验档案（参数 / 方法 / 原理 / 收益）

共 12 个实验：4 个有效（绿）、7 个证伪（红）、1 个进行中（黄）。证伪同样是成果——避免了在正式提交上重复试错。

E1 · SFT 微调 r16 有效

Qwen3-14B + LoRA ｜ 2 epochs ｜ 综合 0.3511 → 0.5498
参数
r=16, alpha=32, all-linear, dropout=0.05, lr=1e-4, bs=1×grad_accum 16, max_len=6144, bf16, warmup 5%, 2 epochs
方法
只对 assistant 答案计算 loss（completions-only），并按官方 loss_scale 忽略空 think 块
原理
LoRA 只训练低秩增量、冻结原模型，显存开销小；completions-only 让模型专注学"怎么答"而不是背题面
训练
最终 loss 0.515（约 2 小时）
收益
+0.1987（+57%）—— 本轮最大的单项提升

E2 · SFT 微调 r32 有效（微增）

LoRA 秩加倍 ｜ 2 epochs ｜ 0.5498 → 0.5527
参数
r=32, alpha=64（alpha=2r），其余与 E1 完全相同
方法
仅增大 LoRA 容量，验证"容量是否是瓶颈"
原理
r 越大可表达的参数增量越多；但本任务瓶颈在数据/口径，不在容量
训练
最终 loss 0.504
收益
+0.0029（+0.5%）—— 说明继续加大 r 已饱和

E3 · vLLM 推理加速 有效（工程）

HF generate → vLLM 离线批量 ｜ 生成 8.7×
参数
vLLM 独立 venv ｜ bf16 ｜ max_model_len=8192 ｜ gpu_util=0.95 ｜ 启用 LoRA ｜ VLLM_USE_FLASHINFER_SAMPLER=0
方法
把逐条 HF 生成替换为 vLLM 离线批量推理，接口与输出格式不变
原理
PagedAttention + 连续批处理，大幅提高显存与算力利用率
收益
val 生成 84 min → 9.6 min；综合 0.5527 → 0.5538（任务级无损，非逐位一致）
坑位
本机无 nvcc → 必须关 FlashInfer sampler；VLLM::EngineCore 残留进程会占 ~44GB 需显式清理

E4 · ⑥ 立场 logit 校准 有效 ★ 最佳

无标签先验匹配 ｜ 0.5527 → 0.5678
参数
b_neutral = +0.7，b_oppose = −0.5（先验分布 L1 = 0.0035）
方法
对每张预测卡做一次前向，取 support/neutral/oppose 的概率；在无标签前提下搜索偏置，使预测立场分布最接近训练集先验分布
原理
立场是第一道硬门槛——立场错，整张卡直接作废。模型天然"中立"偏多，往真实分布上掰一掰，能救回一批卡
收益
+0.0151（+2.7%）｜ 配对成功数 NC 1017 → 1043 ｜ F1 0.7182 → 0.7366
合规
无需标签、无泄漏；val 仅用于验收

E5 · ⑦ 卡片数 k 扫描截断 证伪

按置信度排序截断 ｜ 收益 ≤ 0
方法
用生成时的 log 概率给卡片排序，截断到 k 张（k=3…7）
结果
k≥5 与基线完全相同；k=3 → 0.4387，k=4 → 0.5104（明显变差）
原理
模型本来就只输出 4~5 张卡（Np≈Ng=1421），没有超过 5 张可截断的空间
收益
0 / 负 —— 无操作空间

E6 · ⑧ 近重复卡片去重 证伪

BGE 议题名相似度去重 ｜ 收益 ≤ 0
方法
议题名 BGE 余弦 > 阈值（0.85 / 0.90 / 0.93 / 0.96）判为重复，保留 logp 更高的
结果
0.5489 / 0.5503 / 0.5503 / 0.5523，全部低于基线 0.5527
原理
模型输出的卡片本就几乎没有近重复；去重反而误删有效卡
收益
负 —— 关闭该方向

E7 · Liger 融合核 证伪

训练速度优化尝试 ｜ 基本无效
方法
启用 Liger-Kernel 的融合算子，减少显存读写
结果
单步 50.04 s → 49.33 s（提升 <2%）
原理
本机是 2 vCPU + HAMi 虚拟 GPU，瓶颈不在算子层
收益
≈0 —— 不使用

E8 · 指令探针 B1 / B2 证伪

在 prompt 末尾追加指令 ｜ 0.5527 → 0.5498 / 0.5495
方法
B1：「议题名用简明概括的主题词命名」；B2：「一个议题一张卡」
结果
B1 = 0.5498，B2 = 0.5495，均比基线低 ~0.018
原理
SFT 模型是按固定 prompt 训练的；临场加话属于分布外扰动，格式与口径都会漂移
收益
−0.018 —— 此路不通

E9 · SC-merge 自一致性合并 证伪（关键）

n=5 采样 + 共识投票 ｜ −0.043 ~ −0.088
方法
T=0.7 每题独立采样 5 次 → 议题名 BGE 聚类（thr 0.65/0.80）→ 频次≥F（2/3）保留 → 众数代表卡（名字/立场/证据/未来）→ rescore+⑥
结果
F2/t80 = 0.5246，F3/t80 = 0.4997，F2/t65 = 0.4796，single-best = 0.5527
原理
模型的口径偏差是系统性的，不是采样噪声——5 次都朝同一方向偏，投票消不掉；频次过滤还误伤了"只被看到 1~2 次"的微妙真议题
收益
负 —— 但这是全场最有价值的负结果，直接指向"必须重训"
成本
300 篇 × 5 采样 ≈ 25 分钟（vLLM 加速的红利）

E10 · 失败归因诊断 方法论

把"分数不够高"拆成可操作的技术问题
方法
复刻评分器的匹配逻辑，对 378 张未匹配金标卡逐张归因；统计证据逐字率、议题名与原文的重合度
结果
配对成功但相似度≤0.7：194 ｜ 立场无同调卡：101 ｜ 相似度不足：64 ｜ 配对挤占：19
结果
近失卡 145 张只差 0.05~0.10 ｜ 近失对 cos(议题名)=0.52 vs cos(证据)=0.70
结论
短板是议题命名口径与选哪句证据，不是"读不懂"
收益
决定了后续所有实验的方向

E11 · 字段加权重训（Phase 2） 进行中

给短板字段的 loss 加权
方法
自定义加权交叉熵：议题名 ×2、立场 ×3、未来论点 ×2，其余字段 ×1
参数
r=32, alpha=64, 3 epochs（对照：不加权 3 轮）
原理
诊断显示短板集中在"命名口径 / 立场判断 / 未来论点生成"，就让这几处的 loss 权重更大，逼模型学会标准答案的表达习惯
工程
按 token 定位字段值并加权；loss 按 1024 token 分块计算，避免整段 logits 转 fp32 造成显存溢出
自检
加权 token 精确落在议题名/立场上（如 中日青年友好交流 / neutral），定位准确率 100%

E12 · 训练/推理模式对齐 基础

复刻官方最佳实践
方法
训练与推理统一 enable_thinking=False；assistant 轮的空 think 块不参与 loss
原理
对齐官方 loss_scale=ignore_empty_think，避免模型把算力花在"思考标签"上
收益
与其他模型的行为一致，保证对比公平

6真实案例

以下全部来自 val 集的真实预测，可直接用于讲解。

证据逐字率

金标：100% ｜ 模型：99.18%

模型早已学会"逐字摘抄原文"，原计划的"强制照抄"没有价值。

未来论点的性质

金标逐字率：0%（纯生成）

"未来表态"不可能从原文抄，只能靠训练生成——所以走重训路线。

议题名的口径

原文子串率：金标 13.7% vs 模型 23.7%

金标更"抽象概括"，模型更"贴原文"——这就是命名对不上的根因。

案例一 · 内容读对了，标题起错了

下面三组来自不同文档：模型和标准答案指向的是同一件事，但议题名相似度很低（占判定权重 40%）。

同一个意思模型起的名字标准答案的名字名字相似度证据相似度

7三个关键发现

① 不是"读不懂",是"起名口径"不同

标准答案偏概括性主题词，模型偏爱照抄原文。意思对了，名字对不上，40% 的判定权重白白流失。

② 证据早已"逐字抄"（99.2%）

原计划教它"照抄原文"，一查发现它早会了。真正的问题是内容里那么多句子，它选了哪一句。

③ 错误是"系统性"的,不是"随机"的

同一篇文章让它答 5 遍投票，结果更差（−0.043）。因为每次都往同一方向偏——投票救不了系统偏差，只能靠重训。

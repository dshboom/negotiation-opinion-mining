## 结论

1. **最佳：S1 结构化（证据先行抽取 + 独立未来生成）+ ⑥立场校准 = 0.5773**，比重建基线 0.5688 高 **+0.0085**。
2. **任务拆分本身有效**：同数据同条件下 S1 比 B1 高 **+0.0183**。
3. **偏好优化**：RFT 无校准 0.5720 > 基线，但加 ⑥ 后被抵消；**DPO 全程无增益**。
4. **⑥校准与训练方法有交互**：对 S1 有益（+0.0121），对 RFT 有害（−0.0032）。
5. 所有组均未突破历史 32B 的 0.6082（该数字原始报告尚未核验）。

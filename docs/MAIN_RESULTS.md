# 主结果表（详细版，val 300）

本地 1:1 复刻官方口径 · **不是官方排行榜成绩** · **test 未改动**
（不含 T1 提示词实验，那些是非正向结果，另见 `OVERNIGHT_RESULTS.md`）

评分公式：

```text
综合分 = 0.8 × 抽取分 + 0.2 × 未来观点分
抽取分 = F1 × α        （F1 同时看召回和精确，α 看匹配质量的成色）
未来观点分 = (ROUGE-L + BERTScore) / 2
```

## 一、先解释名词：每个方案到底在做什么

| 简称 | 完整名称 | 用大白话说明 |
|---|---|---|
| 基座零训练 | Qwen3-14B 直接推理 | 不做任何微调，只用提示词让模型输出，作为最低参照 |
| **联合任务微调** | 联合抽取 + 未来预测 SFT | 一篇文档一次性输出“观点卡 + 未来表态”，是原来的主方案（对照用） |
| **结构化拆分** | 证据先行抽取 + 逐卡独立未来生成 | 把任务拆成两步：① 先抽“证据→议题名→立场”的观点卡；② 再针对每张卡单独预测未来表态 |
| **RFT** | 拒绝采样微调（Rejection-sampling Fine-tuning） | 让模型在**没见过的留出文档**上生成多个答案，挑出质量最高的，用它继续做监督微调（只学正例） |
| **DPO** | 直接偏好优化（Direct Preference Optimization） | 同一条输入有“较好的答案”和“较差的答案”，训练模型提高前者、压低后者（学正例+负例对比） |
| **⑥ 立场校准** | 无标签立场先验校准 | 不改模型，只在输出后用模型自己的立场概率 + 训练集立场分布，把倾向性偏差修正回来；**不使用验证集金标** |

### 每组在比什么

- **第 1 名（0.5773）**：结构化拆分后在输出端加 ⑥立场校准。目前最好。
- **第 8 名（0.5469）vs 第 6 名（0.5652）**：这是**唯一严格同条件**的对照——同样 2000 条、同样无校准，只差“任务是否拆分”。结论：**拆分本身带来 +0.0183**。
- **第 3 名（0.5720）**：RFT 只学高质量正例，不校准就超过基线。
- **第 5 名（0.5688）**：RFT 再加 ⑥校准反而被抵消，说明校准与 RFT 不叠加。
- **第 7 名（0.5646）**：DPO 学偏好对，反而低于同条件的结构化拆分，**证明在当前 255 对规模下 DPO 无效**。
- **第 4 名（0.5688）**：原方案用全量数据 + 校准，是历史主线参照，**不是严格对照**。

## 三、为什么这么多组都只用 2000 条？

这是被问到最多的问题，原理如下。

原来训练集有 **2400 篇**。为了做“偏好优化”（RFT/DPO），需要一批**模型没见过的文档**来生成候选答案——否则模型可能只是背下了训练答案，评出来的偏好是假的（“伪留出”）。

所以我们把 2400 篇按下述方式切开：

```text
训练集 2400 篇
├── fit（用于训练）        2000 篇
└── holdout（不参与训练）   400 篇
        ├── 偏好来源   300 篇  → 生成候选、构造偏好对
        └── 偏好确认   100 篇  → 只用于检查，不参与训练
```

因为有了这个划分：

- **所有新方法**（结构化拆分、RFT、DPO）都只能在这些 **2000 条 fit** 上训练，才保证“留出集没被见过”。
- **重建基线**是原方案，直接用**全量 2400 条**训练，所以它的数据比所有新方法都多。

**因此要这样读表：**

- **公平比较**：第 8 vs 第 6（都是 2000、都无校准）→ 证明结构拆分有效。
- **与基线比要小心**：第 1 名（2000 条）比第 4 名（2400 条）高 0.0085，是在**数据更少**的情况下做到的，含金量高于字面差距；但两者数据量不同，不能当成同一条件的严格胜负。

### 下一步能白捡的分

把**已经验证有效的最佳配方（结构化拆分 + ⑥校准）用回全部 2400 条**训练。这是最直接、最可能继续涨分的一步，也能消除“2000 vs 2400”的口径不一致。

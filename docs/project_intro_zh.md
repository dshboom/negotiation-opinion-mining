## 0. 一句话讲清楚

**给 AI 一篇外交/时政长文，让它自动回答四个问题：**

1. 这篇文章在谈哪些**议题**？
2. 每个议题上是什么**立场**（支持 / 反对 / 中立）？
3. 判断的**依据是原文哪几句话**？
4. 这件事**接下来会怎么表态**？

> 🗣️ **开场就说这句**：
> "说白了，我们是在训练 AI 读懂时政新闻——不光读懂，还要像分析员一样划重点、判态度、引原文、做预测。"

---

## 1. 比赛到底要交什么

### 输入
一篇文档（约 1500 字），附带**文档类型**（记者会 / 联合声明 / 评论文章…）和**发布日期**。

### 输出（一个 JSON，一篇文章一份）
```json
{
  "issue_list": [
    {
      "issue_name": "反对脱钩断链",                    // 议题名
      "stance": "support",                             // 立场：support/oppose/neutral
      "argument_chain": ["原文里的原句1", "原文里的原句2"]  // 证据链（必须逐字来自原文）
    },
    { "issue_name": "...", "stance": "...", "argument_chain": ["..."] }
  ],
  "future_argument": [
    "与第 1 张议题卡对应的未来表态预测，80~120 字",
    "..."
  ]
}
```

**两个关键约束**
- 证据链必须是**原文的逐字摘抄**（不能自己改写）
- `future_argument` 条数必须和 `issue_list` **一一对应**

> 🗣️ **类比一句**："就像考试里的'阅读理解 + 判断题 + 论述题'三合一，最后还要写一段'预测题'。"

## 2. 怎么算分（总分 = 80% 抽取 + 20% 预测）

### 第一部分：观点抽取（占 80 分）

打分是**三道关**：

| 关卡 | 规则 | 通俗解释 |
|---|---|---|
| ① 立场关 | 立场必须**完全一致**才能配对 | 你说"支持"，答案也"支持"才有资格比 |
| ② 相似关 | `0.4×议题名相似度 + 0.6×证据链相似度 > 0.7` | 名字像、证据也像，才算"答对这一题" |
| ③ 一对一 | 每张预测卡最多配一张标准卡 | 不能一卡多配来刷分 |
| ④ 质量系数 α | 配对成功的卡再乘"证据像不像原文" | **证据越像原文，分越高** |

然后算：
- **准确率 P** = 答对数 ÷ 模型输出卡片数（答多了扣分）
- **召回率 R** = 答对数 ÷ 标准答案卡片数（漏答了扣分）
- **F1** = P 和 R 的平衡分

### 第二部分：未来观点预测（占 20 分）
把预测的"未来表态"和标准答案对比，用**字面重合度**（ROUGE-L）和**语义相似度**（BERTScore）打分。

### 最终
```
综合分 = 0.8 ×（F1 × α） + 0.2 × 预测分
```

## 3. 常用的几个缩写（别人说起时不再懵）

| 缩写 | 含义 | 备注 |
|---|---|---|
| **NC** | 配对成功的卡片数 | 分子 |
| **Np** | 模型一共输出多少张卡 | 目前约 1411 |
| **Ng** | 标准答案一共多少张卡 | val 共 1421 |
| **P / R / F1** | 准确率 / 召回率 / 调和平均 | — |
| **α** | 证据链"像原文"的系数 | 目前 0.825 |
| **SFT** | 监督微调 | 用标准答案教模型 |
| **LoRA** | 一种省显存的微调方法 | 不动原模型，只训一小块 |
| **vLLM** | 高速推理引擎 | 生成加速 8.7 倍 |
| **val / test** | 验证集 / 测试集 | val 有答案可自查，test 无答案交卷 |

## 4. 数据与规则约束

| 项目 | 内容 |
|---|---|
| 训练集 | **2400 篇**（带标准答案） |
| 验证集 val | **300 篇**（带答案，只用于我们自查） |
| 测试集 test | **300 篇**（无答案，最终交卷） |
| 官方指定基座模型 | **Qwen3-32B** |
| 我们的现状 | 先用本机 **Qwen3-14B** 跑通并优化流程；正式提交再上 32B |

> 🗣️ **重点提醒**："规则要求必须用 Qwen3-32B 做基座。我们先用 14B 把小模型上能做的事全试一遍，把流程和方法论打磨好，最后平移到 32B——这样省时间、也省算力。"

## 5. 我们的技术流水线（一张图看懂）

```
  原始赛题数据（2400/300/300 篇）
        │
        │  ① 数据构造：转成"对话格式"，教模型按格式回答
        ▼
  SFT 微调（LoRA，让 Qwen3 学会这个任务）
        │
        │  ② 生成预测：对 val / test 逐篇输出 JSON
        │     ⚡ 用 vLLM 加速：84 分钟 → 10 分钟
        ▼
  本地评分器（按官方规则 1:1 复刻，可自查）
        │
        │  ③ 后处理优化
        │     ├─ ⑥ 立场校准 → ✅ 有效（+0.015）
        │     ├─ ⑦ 卡片数截断 → ❌ 无效
        │     └─ ⑧ 相似卡片去重 → ❌ 无效
        ▼
  最终提交文件  result_final.jsonl（300 篇）
```

**为什么要有"本地评分器"？**
因为 test 集没有答案，我们必须在 val（有答案）上反复验证每个改动有没有用，避免在正式交卷上瞎试。

> 🗣️ **可以强调**："我们复刻的评分器和官方规则一致，还用两个'极端案例'自检过——把标准答案原样交上去得满分 1.0，把整篇原文当证据交上去得 0.73，说明评分器是准的。"

| 配置 | 综合分 | 相对基座 | 说明 |
|---|---:|---:|---|
| 基座·零训练 | 0.3511 | — | 原始 Qwen3-14B 直接答题 |
| + SFT 微调（r16） | 0.5498 | **+0.199** | 教一遍就大幅提升 |
| + SFT 微调（r32） | 0.5527 | +0.202 | 微调强度加大，略好 |
| + vLLM 加速推理 | 0.5538 | +0.203 | 提速 8.7 倍，分数无损 |
| **+ ⑥ 立场校准** | **0.5678** ★ | **+0.217** | 当前最佳 |
| （参考上界）答案原样照抄 | 1.0000 | — | 评分器自检用 |

## 7. 今天最重要的三个发现（大白话）

### 发现一：模型不是"读不懂"，是"起名字的口径"不一样
标准答案的议题名偏**概括性主题词**，模型喜欢**照抄原文**——
意思是对的，但名字对不上，分数就低。

**真实案例（可直接投屏）**：

| 同一段内容 | 模型起的名字 | 标准答案的名字 | 名字相似度 |
|---|---|---|---|
| 都在说"美国 DART 撞小行星" | DART任务验证偏转 | 动能撞击偏转技术 | 0.48 |
| 都在说"亚太合作不脱钩" | APEC开放区域主义 | **反对脱钩断链** | 0.26 |
| 都在说"边境联合巡逻" | 过境口岸升级 | 联合巡逻机制 | 0.34 |

> 🗣️ **讲解要点**："看第三列——标准答案喜欢用'反对脱钩断链'这种**口号式、概括性**的说法，而模型习惯从原文里拎词。意思完全一样，但判分时'名字像不像'占 40%，所以白白丢分。更关键的是：**这几组的证据句几乎是同一句**，说明它内容读对了，只是'标题没起对'。"

### 发现二：证据链它已经"逐字抄原文"了（99.2%）
我们本来准备教它"证据要照抄原文"，结果一看：它早就会了。
真正的问题是——**内容里那么多句子，它选了哪一句**。

### 发现三：它的错误是"系统性"的，不是"随机"的
我们试过一个办法：让模型把同一篇文章**独立答 5 遍，投票取共识**。
结果**反而更差**（−0.043）。
原因：它每次都在**同一个方向**上偏，投票救不了系统性偏差——只能靠**重新训练**去纠正。

> 🗣️ **这一段最有含金量**："这三条发现，是我们花了一整天做'失败归因'挖出来的。它把一个模糊的'分数不够高'，变成了三个明确的技术问题。"

## 10. 演示流程建议（讲者用）

1. **开场 30 秒**：念第 0 节的"一句话" + 类比
2. **任务演示 2 分钟**：打开第 1 节，带大家看一个真实的输入输出例子
3. **怎么算分 2 分钟**：只讲"三道关"+ 总分公式，细节表格略过
4. **流水线 2 分钟**：指第 5 节的图走一遍
5. **成绩 + 发现 3 分钟**：第 6、7 节——**这是全场高潮**，重点讲"三个发现"
6. **下一步 + 分工 2 分钟**：第 8、9 节
7. **答疑**

**建议准备的道具**
- 一份真实文档 + 模型输出的对照（最好挑一个"模型起名和答案不一样"的例子，最直观）
- 主结果表截图

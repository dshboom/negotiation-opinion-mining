# 本轮 L20 评测产物保留要求

适用：B1联合SFT、S1证据先行抽取、S1独立未来生成及后续RFT/DPO实验。

评测推理尚未接入。实现时必须满足以下要求；这份约定不代表产物已生成。

## 每次推理必须保留

- `raw_generations.jsonl`：按样本/卡片保存未经解析、修复、校准或合并的模型正文，包括失败、空输出和截断输出。
- `generation_audit.jsonl`：sample_id、split、实验编号、卡片索引、实际输入提示（或私有可重建引用）、适配器、采样参数、finish_reason、输入/输出token数、解析状态和错误；结构化链路分别保存抽取与未来模块记录。
- `pred_before_postprocess.jsonl`：解析后的原始预测。
- `pred_scored.jsonl`：实际送入评分器的预测。任何后处理另存，不覆盖前一份。
- `report.json`：完整指标与逐样本评分（启用per-sample）。
- `manifest.json`：代码版本/脚本哈希、数据哈希、模型/适配器标识与哈希、软件版本、时间、样本数、推理参数及产物SHA256。

## 错误分析与持久保留

- 导出逐卡CSV、逐篇CSV及完整预测/金标对照JSON，显式标记实验与split。
- 验收原始记录与预测的ID/数量；每个未来生成请求关联源样本和卡索引；失败不可从统计中静默排除。
- 原始与审计记录先安全落盘，再写完成状态；断点恢复不得只根据预测存在跳过缺失的原始记录。
- 重跑写入独立run目录，不覆盖旧输出；原始文件不进行后处理。
- 完成后下载到本机私有 `model_outputs` 并校验哈希，下载成功前不删除远端副本。
- 原文、原始生成、预测、金标和可重建敏感提示仅私有保存，不上传公开GitHub/Pages；公开内容仅配置摘要和聚合成绩。

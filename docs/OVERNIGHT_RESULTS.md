## 三、主要发现

1. **任务拆分有效。** 同数据、同无校准下，S1 结构化比 B1 联合高 **+0.0183**，抽取与未来同时改善。这验证了“证据先行抽取 + 独立未来生成”的结构假设。
2. **RFT 有效但幅度有限。** 用 255 条真实高质量候选继续 SFT（仅 9 分钟），抽取分 +0.0071、未来 +0.0051，未校准综合 **0.5720**，已超过基线。
3. **DPO 在当前规模下无效。** 同样 255 对、cached-reference 参考模型，未校准 0.5646，低于 S1。抽取任务更适合正例强化（RFT），不适合小规模负例对比。
4. **⑥校准存在交互效应。**
   - 对 S1 大幅有益：+0.0121 → **0.5773（最佳）**；
   - 对 RFT **有害**：0.5720 → 0.5688（RFT 已学到更好的立场分布，额外先验反而破坏）；
   - 说明后处理与训练方法不能随意叠加。
5. **最佳成绩 = S1 + ⑥ = 0.5773**，比本次重建基线高 **+0.0085**，比 S1 未校准高 +0.0121。

## 四、实验设置（可复现）

- 数据：train 2400 → fit 2000 / holdout 400（按**相同原文整组**划分）；holdout 再分 preference-source 300 / dev 100。
- fit/holdout、train/val **无完全重复原文**；近重复未检查。
- 训练：Qwen3-14B，LoRA r32 / α64，all-linear，lr 1e-4，2 epochs，completions-only，`enable_thinking=False`，bs1×ga16，max_len 6144。
- 偏好数据：fit-only 模型在 300 条未见样本上生成 4 候选/条（1 确定性 + 3 采样），官方口径排序；**排除截断、解析失败、纯格式差异、长度偏置**；有效对 **255**（44 近似平局，1 长度偏置被排除）。
- RFT：从 S1 抽取适配器继续 SFT，1 epoch，lr 5e-5。
- DPO：cached-reference（参考=S1 抽取适配器），QLoRA NF4，β=0.1，lr 5e-6，1 epoch。
- ⑥校准：仅用模型自身立场概率 + 训练集立场先验，**不使用 val 金标**。
